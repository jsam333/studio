# **App Name**: Brick Breaker Blitz

## Core Features:

- Board Initialization: Game board setup with bricks, paddle, and ball.
- Game Mechanics: Paddle control and ball physics implementation.
- Score and Game Over: Score display and game over screen.

## Style Guidelines:

- Primary color: Blue (#3498db) for the background.
- Secondary colors: White (#ffffff) for the paddle and ball.
- Accent: Orange (#e67e22) for the bricks to add contrast.
- Simple, full-screen layout with the game board centered.
- Smooth ball movement and paddle control.
- Minimalist icons for the score display.
